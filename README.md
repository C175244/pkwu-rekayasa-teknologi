# 🐟 PKWU - Budidaya Ikan Gurame

Website tugas PKWU (Rekayasa Teknologi) tentang budidaya ikan gurame.

## 📋 Isi Website
- Alasan memilih budidaya gurame
- Cara budidaya step-by-step
- Modal awal dan hasil panen
- Pengolahan dan pemasaran

## 🛠 Teknologi
- React.js
- Vite
- Tailwind CSS
- Lucide Icons

## 🚀 Cara Menjalankan
```bash
npm install
